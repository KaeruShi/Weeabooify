# Quick Settings

Customize the look and feel of your Android Quick Settings panel (QS panel).

## Header Styles

Choose from multiple header layout styles to personalize how the top of your QS panel looks.

## Header Image

Set a custom image as the QS header background. Supports adjusting:

- **Header image height** — control how tall the image area is
- **Fade effect** — soft fade at the bottom edge for a seamless blend
- **Hide when landscape** — hide the header image when the device is in landscape orientation

## Pixel Variant

Enable the **Pixel variant** for a black QS panel, matching stock Pixel UI styling.
::: warning Deprecated
Only support for version 5.6 below
:::

## Custom Content

- Set custom **text** in the header area
- Replace or layer a custom **background image**
- Override the **background color**

## Padding Control

Fine-tune spacing independently for:

- **Portrait** orientation
- **Landscape** orientation

::: tip
Padding adjustments let you compensate for notches, punch-holes, or custom status bar heights on your specific device.
:::

## Miscellaneous
- Blur Album Art — apply a blur effect to the album art in the QS panel
- Expand Animation — animate the QS panel expansion when interacting with it
- Hide Stock Media Player *(Deprecated)* — hide the default media player widget in the QS panel
- Hide QS Icons — hide the QS panel icons
- Hide When Landscape — hide the header style when the device is in landscape orientation
