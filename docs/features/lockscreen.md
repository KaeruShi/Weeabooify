# Lockscreen

Weeabooify gives you deep control over your lockscreen's appearance.

## Clock

- **Custom clock styles** — choose from multiple clock designs
- **Custom font** — apply your own font to the clock
- **Clock margin** — fine-tune vertical positioning
- **Clock size** — adjust the clock's size
- **Clock color** — apply a solid or tinted color layer to the clock

## Date

- **Custom date format** — use any date format string (e.g. `EEE, MMM d`)
- **Date margin** — fine-tune vertical positioning
- **Date color** — apply a solid or tinted color layer to the date
- **Date widget** — add a date widget to the lockscreen

## Custom Content

- Set custom text for the lockscreen clock style
- Set a lockscreen clock style image
- Apply a solid or tinted color layer
- Control how much of the screen the background image covers

## Widgets

Add functional **lockscreen widgets** including:

- 🌦️ Weather
- 🔋 Battery
- 🗓️ Date
- 🖼️ Photos
- ◻️ Spacer
- 📝 Custom Text
- 📲 Device Info
