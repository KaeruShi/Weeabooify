# SystemUI Tweaks

Miscellaneous but powerful SystemUI modifications that fine-tune behavior and appearance across the whole interface.

## Language

- **Custom mixed language** — display the UI in a blended locale independent of system settings

## Status Bar Icon Positioning

- **Wi-Fi right** — move the Wi-Fi icon to the right side of the status bar (iOS-style)
- **Mobile data right** — move the mobile data icon to the right side (iOS-style)
- **System icons spacing** — adjust spacing between status bar icons
- **Battery padding** — add padding around the battery icon indicator

::: warning Deprecated
Only available for version 5.6 below
:::

## Notification Shade

- **Hide QS Footer** — remove the footer area below Quick Settings tiles
- **Hide notification section header** — remove the "Silent" label in the shade
- **Disable skinny notification** — use full-width notification cards instead of the compact "skinny" style
- **Adjust lockscreen max notifications** — set how many notifications are shown on the lockscreen

## Lockscreen Cosmetics

- **Hide lockscreen lock icon** — remove the padlock icon shown below the clock
- **Hide lockscreen status bar** — hide the top status bar while on the lockscreen
- **Hide lockscreen indicator text** — hide the "Swipe up to unlock" or similar hint text
