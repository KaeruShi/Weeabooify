# Icon Pack & Shapes

Replace and customize system icons and UI element shapes throughout the status bar, notification panel, and Quick Settings.

## Status Bar Icons

Override the default system icons with custom alternatives:

- **Signal icon** — cellular signal strength indicator
- **Wi-Fi icon** — wireless connection indicator
- **Mobile data icon** — data activity arrows
::: info
Some icons are not available yet on the latest version.
:::

## Notification Background Styles

Apply custom background styles to individual notification cards in the shade. Choose from multiple style presets to match your theme.

## QS Tile Background Shapes

Customize the shape of Quick Settings tile backgrounds. Options go beyond the default rounded rectangle to include other geometric styles.

::: warning Deprecated
Quick Settings tile icon pack support is deprecated and only supports Android 14 below.
:::
