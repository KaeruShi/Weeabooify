# Installation

Follow these steps to get Weeabooify running on your device.

## Steps

**1. Install the Weeabooify app**

Download and install the APK. For the Trial Version, you can install it directly. For the Full Version, you'll receive access after purchase — contact [@KaeruShi](https://t.me/kaerushi) on Telegram with your payment screenshot.

**2. Reoptimize in LSPosed**

Open the **LSPosed** manager and tap **Reoptimize** on the Weeabooify module. This ensures the hook is compiled correctly.

**3. Enable and select scope**

Enable the **Weeabooify** module in LSPosed, then set the scope to:
- ✅ **Framework**
- ✅ **SystemUI**
- ✅ **Settings**

**4. Configure the app**

Open **Weeabooify**, grant all requested permissions, and log in to your account (Full Version only).

**5. Reboot**

Wait for the installation process to complete, then **reboot your device** and enjoy 🎉
