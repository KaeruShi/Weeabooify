# Requirements

Before installing Weeabooify, make sure your setup meets the following requirements.

## Android Version

- **Android 12 – 16** (Anti-Entropy variant)

::: warning Android 15 and below
If you're on **Android 15 or below**, use **version 5.6** instead of the latest release.
:::

## Root Manager

You need one of the following root solutions:

- [Magisk](https://github.com/topjohnwu/Magisk)
- [KernelSU](https://github.com/tiann/KernelSU)
- [SukiSU](https://github.com/SukiSU-Ultra/SukiSU-Ultra)
- [APatch](https://github.com/bmax121/APatch)

## LSPosed Framework

- [LSPosed](https://github.com/JingMatrix/LSPosed) — optionally paired with [ZygiskNext](https://github.com/Dr-TSNG/ZygiskNext/releases/latest) if required by your root setup

## Recommended

- A **custom recovery with decryption support** (e.g. OrangeFox, TWRP) is strongly recommended as a fallback in case of bootloop.

::: tip KernelSU users
Root access for Weeabooify must be **manually granted** via the KernelSU app.
:::
