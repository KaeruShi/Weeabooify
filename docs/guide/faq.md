# FAQ

Frequently asked questions about Weeabooify.

## Is my device supported?

Weeabooify supports **Pixel devices** and **AOSP-based custom ROMs**.

The following are **not supported**:
- MIUI / HyperOS (Xiaomi)
- OneUI (Samsung)
- OxygenOS (OnePlus)
- ColorOS (OPPO/Realme)
- iOS

## What is Anti-Entropy (AE)?

**Anti-Entropy (AE)** is the primary variant of Weeabooify targeting **Android 12 and above**.

The other variant, **Schicksal**, targets Android 10 and uses the Substratum overlay engine. Each variant is sold separately.

## I'm on Android 15 or below, which version should I use?

Use **version 5.6** if you're on Android 15 or below. The latest release targets Android 16 QPR0.

## Does it work without root?

No. Weeabooify requires root access (via Magisk, KernelSU, SukiSU, or APatch) and the LSPosed framework to function.
