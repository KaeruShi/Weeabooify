# Introduction

**Weeabooify** is a powerful theme engine that allows you to customize your Android SystemUI with a beautiful and aesthetic touch — including the QS panel, lockscreen, icons, and more.

It works by hooking and modifying Android's SystemUI and Framework components at runtime via the [LSPosed](https://github.com/JingMatrix/LSPosed) engine. No system partition changes, no heavy overlay flashing.

## Variants

Weeabooify is offered in two variants:
